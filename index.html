The AI system I build and run everything with, including the contractor deployment above. How Core is built

One engine. Five instances. One brain.

5 instances of one engine. One writer to the shared baseline, four pull-only seats
106,730 entities and 171,053 relationships in one shared brain, org partitioned with row-level security
Every action intercepted first, and released only on a one-time token bound to the exact command

One engine, instanced

The engine lives on GitHub as a baseline. One instance is its only writer. The other four pull it on every open against a manifest that says which paths are shared, which belong to the seat and may never be overwritten, and which files to retire. The single writer rule is enforced, not agreed. A fix written once reaches four other running agents on their next open.

Gates, not advice

Every outward action, an email, a push, a calendar write, a network call, is intercepted first and proceeds only on a one-time token minted from a review agent’s APPROVE, bound to the exact command. A change to the trust root returns ASK and never APPROVE, and no code path converts ASK into a token, so the only way it lands is me typing the command in my own terminal.

One brain, five tenants

One Postgres database, org partitioned with row-level security, read-all and write-own by design. Session transcripts feed extraction workers in batches, and no checkpoint merges until it exists, parses and matches the shape the merge expects, because a worker’s done is a claim, not evidence. Retrieval fuses vector search, full text, graph traversal and relationship vectors. A nightly job probes for debt and rebuilds only when it finds some.

It watches itself

Twenty-nine hooks across nine lifecycle events, every fire logged. Corrections that recur become installed behaviors that ship live behind a test gate and roll back to quarantine when their measured outcomes say so. Nine gates that fired after the reply had already gone out were deleted, because a block that cannot block is a lie about enforcement.

Proof it works

The first thing it built for someone else is the contractor’s system above. I did not solve reliability with more gates. I built agents with independent access to the facts and let them check each other’s work.
